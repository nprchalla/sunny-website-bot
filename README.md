🌤️ Sunny Website Bot
An AI‑powered coaching assistant built end‑to‑end with real‑time voice, custom GPT integration, and a fully responsive website.

🚀 Overview
Sunny Website Bot is a complete AI coaching experience delivered through a modern, multi‑page website. It combines a clean UI, real‑time voice conversations, and intelligent responses powered by a custom GPT model. The goal is to create a natural, supportive coaching interaction directly in the browser.
This project was built end‑to‑end — frontend, backend, AI integration, and deployment.

✨ Features
🧠 AI Coaching Assistant
- Integrated custom GPT for personalized coaching
- Real‑time responses with contextual understanding
- Designed to feel natural, supportive, and conversational
  
🎤 Voice Interaction
- Built using OpenAI Realtime Voice API
- Users can speak directly to Sunny
- Smooth, low‑latency voice conversations
  
🌐 Full Website Experience
- Multi‑page layout (Home, About, Coaching, Contact, etc.)
- Clean, responsive UI
- Simple navigation and user‑friendly design
  
🛠️ Backend Services
- Node.js/Express server
- Handles voice streaming, GPT requests, and session management
- Secure API communication
  
📦 Deployment
- Fully deployed end‑to‑end
- Ready for demos, testing, and future enhancements

🔧 Setup Instructions
1. Clone the repo
git clone https://github.com/nprchalla/sunny-website-bot
cd sunny-website-bot

2. Install dependencies
npm install


3. Add environment variables
Create a .env file based on .env.example:
OPENAI_API_KEY=your_key_here
PORT=3000


4. Start the server
npm start


5. Open the website
Visit:
http://localhost:3000
